# Glossário Decifra (EN → pt-BR)

Documento de referência canônica para toda a tradução e localização do Decifra. Qualquer copy nova (UI, API prompts, e-mail, marketing, conteúdo SEO) deve consultar este arquivo antes de escolher um termo.

- **Status**: vivo (v1.0, 2026-05-12)
- **Mantido por**: Luana Micheau + colaboradores
- **Escopo**: produto Decifra (web + futuro RN), interpretação de exames laboratoriais femininos para o mercado brasileiro
- **Padrão de língua**: português brasileiro culto neutro, sem regionalismos
- **Audiência**: mulheres brasileiras adultas, escolaridade média a alta, alfabetização em saúde variada

## Como usar este glossário

1. Antes de escrever ou traduzir copy nova, busque o termo aqui (Cmd+F).
2. Se o termo existe, use a forma canônica. Não invente sinônimo.
3. Se o termo não existe e for genérico, traduza com bom senso e abra um PR adicionando aqui.
4. Se o termo for ambíguo (vários pt-BR plausíveis), use a coluna "Notas" para decidir pelo contexto.
5. Termos clínicos novos passam por revisão antes de entrar (médica nativa BR, FEBRASGO/SBEM/SBPC/ML quando aplicável).

## Como adicionar entradas

PR para `docs/glossary.md` com:

- Entrada na tabela correta (alfabética dentro da seção)
- Justificativa de 1 linha se a escolha não for óbvia
- Referência (link FEBRASGO, SBEM, SBPC/ML, Manual MSD pt-BR, etc.) para termos clínicos

## 3. Marcadores e exames (grafia canônica pt-BR)

Laudos brasileiros podem usar a forma em inglês também. O Decifra reconhece ambas; este glossário define a forma que **nós** usamos em copy.

**Padrão bilíngue de primeira menção (BR/EN):** para marcadores cuja sigla brasileira difere da internacional, escreva primeiro a forma BR e a internacional entre parênteses na primeira ocorrência da entrada. Em texto corrido seguinte, alterne "BR/EN" (ex.: "TGO/AST", "TGP/ALT") para acostumar a leitora com a nomenclatura internacional sem perder o termo que ela vê no laudo. Exemplos canônicos: **TGO (AST)**, **TGP (ALT)**, **PCR ultrassensível (PCR-us)**, **TFG estimada (TFGe)**.

### Verbos preferidos para hedging clínico

NÃO escreva "isso significa que você tem X". Escreva:

- **pode indicar** (não "indica")
- **sugere** (não "comprova", "confirma")
- **costuma estar associado a** (não "causa")
- **vale acompanhar** (não "deve preocupar")
- **converse com sua médica** (sempre que houver dúvida clínica)

### Intensificadores a evitar

- "Muito" / "super" / "bem" como advérbios casuais ("muito baixo", "bem alto")
- Preferir: "abaixo da faixa", "acima da faixa", "no limite inferior", "no limite superior"

## 14. Voice cheat-sheet de uma linha

> Brasileira, atenta, sem pressa, sem alarme. Fala como ginecologista boa e cuidadosa, não como bula nem como influencer. Explica o termo técnico, valida a dúvida, sugere conversar com a médica. Nunca diagnostica, nunca minimiza, nunca dramatiza.
