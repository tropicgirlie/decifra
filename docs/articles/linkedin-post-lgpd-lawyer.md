## Observações para depois de postar

1. **Engajamento**: responde TODO mundo que comentar, mesmo "passando pra apoiar". Algoritmo LinkedIn premia replies do autor nas primeiras 2h.
2. **DM**: quem mandar mensagem, agende um vídeo de 15min antes da consulta paga. Filtra rapidamente quem tem o perfil certo.
3. **Filtrando indicações**: peça portfólio antes de fechar. Quer alguém que já viu **healthtech ou plataforma com dado sensível**, não LGPD genérica de e-commerce.
4. **Segundo post (em 2 semanas, se este não converter)**: mude o ângulo. "Sou solo, construindo healthtech feminina, e descobri que a LGPD aplicada a saúde é mais complexa do que parece. Estou procurando alguém para uma consulta de 1h sobre os pontos mais cinzentos." Tom mais vulnerável atrai outro tipo de network.
5. **Cross-post**: este texto traduzido para inglês não rende no mercado BR. Não cross-poste em EN para este pedido. Para network EN, faça post separado em outra ocasião.
